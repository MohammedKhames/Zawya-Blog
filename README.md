# 📸 Zawya Blog - مدونة زاوية للتصوير

**Zawya Blog** is a modern, professional, and fully responsive photography blog designed to share tips, tricks, and insights from the world of photography. Featuring a stunning dark-themed UI with glassmorphism effects, it provides an immersive reading experience for photography enthusiasts.


---

## 🚀 Features

- **Modern Aesthetic**: Dark mode design with gold accents, glassmorphism, and smooth animations.
- **Fully Responsive**: Optimized for Mobile, Tablet, and Desktop viewports.
- **Dynamic Content**: Rich post details with table of contents, related articles, and category badges.
- **Categorization**: Easy exploration of content through specialized categories (Nature, Lighting, Landscapes, etc.).
- **Newsletter Integration**: Clean and engaging newsletter subscription sections.
- **SEO Optimized**: Built with semantic HTML and performance in mind.

## 🛠️ Tech Stack

- **Framework**: [React.js](https://reactjs.org/) (Vite)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Routing**: [React Router DOM](https://reactrouter.com/)
- **State Management**: Built-in React Hooks (`useState`, `useEffect`, `useParams`).
- **Icons**: SVG-based custom icons and Heroicons.

---

## 📦 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- npm or yarn

### Installation

1. **Clone the repository:**
   ```bash
   git clone [repository-url]
   cd zawya-blog
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```

# 📸 مدونة زاوية - Zawya Photography Blog

**مدونة زاوية** هي منصة عصرية واحترافية متخصصة في فن التصوير الفوتوغرافي، تهدف إلى مشاركة أسرار المحترفين ونصائح عملية لتطوير مهارات المصورين. تتميز المدونة بتصميم داكن فاخر (Dark Theme) مع تأثيرات زجاجية (Glassmorphism) لتوفير تجربة قراءة غامرة.

## ✨ المميزات الرئيسية

- **تصميم عصري**: واجهة مستخدم داكنة مع لمسات ذهبية وتأثيرات بصرية جذابة وحركات سلسة.
- **متجاوب بالكامل**: متوافق تماماً مع جميع أنواع الشاشات (هواتف، أجهزة لوحية، حواسيب).
- **محتوى ديناميكي**: صفحات مقالات غنية تحتوي على جدول محتويات، مقالات ذات صلة، وتوسوم تصنيفات واضحة.
- **تصنيفات ذكية**: إمكانية استكشاف المحتوى بسهولة عبر التصنيفات المتخصصة (تصوير الطبيعة، الإضاءة، المناظر، إلخ).
- **نشرة بريدية**: نظام اشتراك جذاب للبقاء على اطلاع بآخر النصائح والمقالات.
- **تحسين محركات البحث**: مبني باستخدام HTML دلالي ومعايير أداء عالية.

## 🛠️ التقنيات المستخدمة

- **الإطار البرمجي**: [React.js](https://reactjs.org/) (مع Vite)
- **التنسيق (CSS)**: [Tailwind CSS](https://tailwindcss.com/)
- **التنقل**: [React Router DOM](https://reactrouter.com/)
- **الخطوط**: خط [Cairo](https://fonts.google.com/specimen/Cairo) العربي المميز.
